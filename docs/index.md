## Rédiger une procédure

1. Décrire l'objectif et l'environnement.
2. Lister les prérequis et précautions.
3. Expliquer les étapes avec leurs commandes.
4. Vérifier le résultat obtenu.
5. Prévoir un retour arrière si nécessaire.
