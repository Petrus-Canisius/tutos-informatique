# Premiers pas avec Git

<div class="kb-doc-meta"><span>Git et GitHub</span><span>Initiation</span><span>Exemple technique</span></div>

<div class="kb-doc-intro"><strong>Objectif.</strong> Comprendre les commandes essentielles d'un dépôt Git.</div>


## Vérifier l'installation
```powershell
git --version
```

## Vérifier l'état du dépôt
```powershell
git status
```

## Enregistrer et publier des modifications
```powershell
git add .
git commit -m "Mettre à jour la documentation"
git push
```

## Vérification
La modification est visible dans l'historique du dépôt sur GitHub.
