# Premiers pas avec Git

## Vérifier l'installation
```powershell
git --version
```

## Vérifier l'état du dépôt
```powershell
git status
```

## Enregistrer et publier des modifications
```powershell
git add .
git commit -m "Mettre à jour la documentation"
git push
```

## Vérification
La modification est visible dans l'historique du dépôt sur GitHub.
