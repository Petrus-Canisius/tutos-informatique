# Glossaire technique

| Terme | Définition opérationnelle |
| --- | --- |
| **AD DS** | Active Directory Domain Services : service d'annuaire et de domaine Windows. |
| **ACL** | Access Control List : liste d'entrées autorisant ou refusant des droits sur un objet. |
| **AGDLP** | Modèle de groupes : comptes → groupes globaux → groupes locaux de domaine → permissions. |
| **Azure Arc** | Services de gestion et d'inventaire hybrides pour des ressources situées hors d'Azure et dans Azure. |
| **CAL** | Client Access License : droit d'accès soumis aux conditions de licence applicables. |
| **DC** | Domain Controller : serveur exécutant AD DS pour un domaine. |
| **DHCP** | Protocole attribuant des paramètres IP aux clients. |
| **DNS** | Service de résolution de noms et de découverte de services. |
| **DSRM** | Directory Services Restore Mode : mode de restauration des services d'annuaire. |
| **FSMO** | Flexible Single Master Operations : rôles AD à titulaire unique selon la portée. |
| **GPO** | Group Policy Object : ensemble de paramètres de stratégie liés à l'annuaire. |
| **GPT** | GUID Partition Table : format de table de partitions, à distinguer des stratégies de groupe. |
| **Hyper-V** | Hyperviseur Microsoft de virtualisation de machines. |
| **Kerberos** | Protocole d'authentification par tickets utilisé notamment dans AD. |
| **LDAP** | Protocole d'accès à un annuaire. |
| **LAPS** | Local Administrator Password Solution : solution de gestion et rotation de mot de passe local administrateur. |
| **NPS** | Network Policy Server : rôle Microsoft prenant en charge des politiques d'accès et RADIUS. |
| **OU** | Organizational Unit : conteneur logique AD pouvant servir à déléguer et cibler des stratégies. |
| **PRA** | Plan de reprise d'activité après incident majeur. |
| **RPO** | Recovery Point Objective : perte maximale de données tolérée, exprimée en temps. |
| **RTO** | Recovery Time Objective : délai cible de restauration d'un service. |
| **ReFS** | Resilient File System : système de fichiers Windows orienté certains scénarios de stockage. |
| **RSAT** | Remote Server Administration Tools : consoles et outils d'administration à distance. |
| **Server Core** | Option d'installation de Windows Server sans expérience de bureau complète. |
| **SMB** | Server Message Block : protocole de partage de fichiers et autres ressources. |
| **SRV** | Enregistrement DNS indiquant un service, son hôte et son port. |
| **SYSVOL** | Répertoire répliqué des contrôleurs de domaine contenant notamment des éléments liés aux GPO. |
| **UEFI** | Interface micrologicielle de démarrage moderne. |
| **VBS** | Virtualization-Based Security : sécurité fondée sur des fonctions de virtualisation matérielle. |
| **VHDX** | Format de disque virtuel utilisé par Hyper-V. |
| **WinRM** | Windows Remote Management : mécanisme d'administration distante, notamment pour PowerShell. |

Ce glossaire couvre les notions présentes dans les modules publiés et les termes structurants des modules à venir.
